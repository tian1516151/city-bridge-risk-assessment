# 城市桥梁安全风险评估软件

这是一个无需安装依赖的本地网页工具。双击 `index.html` 即可打开。

## 已实现功能

- 按附录 H 表 H.1 自动筛查是否应优先评估
- 按表 H.7、H.8 输入 13 项可能性指标与 7 项后果指标
- 按表 H.9 参考权重计算可能性得分 P 与后果得分 C
- 按表 H.2、H.3 分级，按表 H.5 判定 I–IV 风险等级
- 输出表 H.6 对应的管控建议与逐项计分明细
- “载入附录示例”按钮用于核对示例录入和计算过程

> 本软件为辅助计算工具。附录 H 说明，评估小组可结合工程实际从指标体系中选取或补充指标，并对参考权重作适当调整。

## 附录示例校核说明

附录表 H.10 列出的可能性示例得分为 **3.44**，但按该表同时列出的指标分值与表 H.9 权重逐项线性相乘后，结果为 **3.64**（其中 P21 的 2 分 × 0.08 = 0.16）。本工具采用附录文字所述的“各项指标分值分别乘以对应权重系数后线性加权求和”计算法，因此示例显示 3.64；两者均属于可能性等级 2，最终风险等级不受这 0.20 差异影响。
